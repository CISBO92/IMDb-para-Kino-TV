# Sincronizador de Notas IMDb para Kino TV

Este plugin adapta el concepto de sincronización de metadatos de plataformas de servidor a **Kino TV**, inyectando calificaciones de IMDb y Rotten Tomatoes directamente en tus fichas de video en tiempo real.

## Instalación en Kino
1. Abre Kino TV en tu dispositivo móvil o Android TV / Fire TV.
2. Dirígete a **Ajustes > Plugins > Agregar**.
3. Introduce la dirección de este repositorio: https://github.com/CISBO92/IMDb-para-Kino-TV.git
4. Guarda los cambios para activar el catálogo.

## Configuración Obligatoria
Para que las puntuaciones se muestren correctamente, ingresa a la configuración del plugin desde la interfaz de Kino y coloca tu **OMDb API Key** personal.
